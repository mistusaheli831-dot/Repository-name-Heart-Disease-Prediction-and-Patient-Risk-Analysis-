Heart Disease Prediction and Patient Risk Analysis

Project Overview

This project predicts the likelihood of heart disease using Machine Learning techniques.

Algorithms Used

1. Linear Regression
2. Logistic Regression
3. K-Nearest Neighbors (KNN)
4. K-Means Clustering

Project Workflow

1. Collect Data
2. Preprocess Data
3. Analyze Data
4. Build Machine Learning Models
5. Optimize the Model
6. Display Results

Final Output

- Heart Disease Prediction (Yes/No)
- Patient Risk Score
- Patient Risk Category (Low, Medium, High)

Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

Dataset

UCI Heart Disease Dataset.

Note

This project is developed for academic purposes only. It is not a clinically validated medical diagnostic system.
