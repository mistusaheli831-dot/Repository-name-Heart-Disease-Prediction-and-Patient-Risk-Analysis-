# Heart Disease Prediction and Patient Risk Analysis

## Project contents
- `Heart_Disease_Prediction_and_Risk_Analysis.ipynb` — complete Google Colab/Jupyter notebook
- `requirements.txt` — Python dependencies

## Run in Google Colab
1. Download and extract this ZIP.
2. Open https://colab.research.google.com/
3. Choose **File → Upload notebook** and upload the `.ipynb` file.
4. Run **Runtime → Run all**.
5. Internet access is needed once to install `ucimlrepo` and fetch the UCI dataset.

## Algorithms included (as requested)
- Linear Regression — estimated score
- Logistic Regression — Yes/No prediction
- KNN — similar-record classification
- K-Means — Low/Medium/High relative clusters
- 5-fold cross-validation and KNN parameter tuning

## Dataset
UCI Heart Disease, Cleveland subset (303 instances, 13 features).
Original dataset: https://doi.org/10.24432/C52P4X
License: CC BY 4.0. Cite the original UCI creators when reusing the dataset.

## Important limitation
This is an academic demonstration only. The model score is not a medically validated risk estimate or diagnosis. Do not use it for medical decisions.
